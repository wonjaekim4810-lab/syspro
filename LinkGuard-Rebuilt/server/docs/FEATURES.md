# 특징 추출의 범위

이 구현은 Sahingoz 외(2019)의 Table2와 WDM·RWDM·MAM 흐름을 참고한 재구성본입니다. 원 논문 코드가 아니며 아래 정의는 이 프로젝트의 구체적인 선택입니다. 학습과 예측은 같은 특징 이름·순서·스키마·언어 자료와 오프라인 PSL을 사용해야 합니다.

## 모듈

- **WDM:** 숫자를 제외한 문자 토큰을 로컬 사전과 비교하고 붙은 단어를 분리합니다. 7자를 초과하고 80자 이하인 미등록 토큰을 대상으로 길이 3 이상 부분문자열을 비중첩 동적 계획법으로 분리합니다. 알려진 문자 범위를 최대화하고 더 긴 단어를 우선합니다. 최소 두 알려진 구간이 필요하며 미지 구간은 버리지 않습니다. 사전에 있는 긴 단어와 브랜드·키워드는 보존합니다.
- **RWDM:** 로컬 영어 자료와 사전의 문자쌍 전이 확률에 0.2 평활화를 적용하고 기하평균 점수로 무작위 문자열 신호를 얻습니다. 길이 5 이상 미등록 단어의 0.025 미만 점수를 무작위 신호로 계산합니다. 해당 단어는 개수를 센 뒤 MAM과 정확 일치·타깃·기타 단어 계산에서 제외합니다. 언어 자료와 임계값은 실험용이며 학습 URL의 피싱 확률이 아닙니다.
- **MAM:** 정확한 일치는 유사어 개수에서 제외하며 길이 4~64 토큰과 길이 4 이상 타깃을 대상으로 Levenshtein 편집 거리를 계산합니다. 기본 최대 거리 1, 토큰 길이 8 이상은 2를 사용합니다. 일치나 유사어는 사칭 확정 또는 도메인 소유권 확인이 아닙니다.

도메인 구분은 네트워크 갱신 없는 로컬 Public Suffix List를 사용하고 private suffix도 구분합니다. Unicode 호스트를 IDNA로 정규화하는 기능이 영어 NLP의 한국어 지원 성능을 보장하지는 않습니다. URL은 HTTP(S) 문자열로만 검사하고 대상 사이트에 접속하지 않습니다.

## 40개 특징 그룹

| 그룹 | 개수 |
| --- | ---: |
| 원시 단어 수·공식 목록·단어 길이 통계·분해·키워드·브랜드·유사어·무작위·타깃·기타 단어 | 17 |
| 등록 레이블·하위 도메인·경로의 숫자 수 | 3 |
| 하위 도메인 수·무작위 등록 레이블 | 2 |
| 등록 레이블·하위 도메인·경로 길이 | 3 |
| 알려진 TLD·www/com·Punycode | 4 |
| 특수 문자 `- . / @ ? & = _` | 8 |
| 연속 문자 반복 | 1 |
| HTTPS 사용·IP 호스트 여부 | 2 |
| 합계 | 40 |

원 논문의 Alexa 관련 두 특징에 필요한 원 자료가 없으므로 마지막 두 위치를 HTTPS/IP 여부로 대체합니다. 공개 서비스에 의존하는 조회를 넣지 않습니다. 코드의 `FEATURE_NAMES`가 실제 이름과 순서의 기준입니다. 등록 도메인의 주 레이블은 접미사를 제외합니다. 경로 특징은 쿼리를 포함하고 프래그먼트를 제외합니다. 원시 토큰은 호스트와 경로·쿼리를 한 번 퍼센트 디코딩한 ASCII 영숫자 묶음이며 스킴·프래그먼트는 제외합니다. 특수 문자와 반복 수는 정규화 URL 전체에서 계산합니다.

리소스 지문은 특징 스키마, tldextract 버전, 실제 번들 PSL 내용과 모든 로컬 언어 리소스를 묶어 계산합니다. Unicode 입력과 정규화 결과 모두 4,096 UTF-16 코드 단위를 넘을 수 없고 잘못된 단독 서로게이트는 거부합니다.

결과의 관찰 근거는 URL 특징 설명이며 RF의 실제 특징 기여도나 인과관계 설명이 아닙니다. 기본 사전·말뭉치의 규모와 언어 범위 때문에 실제 데이터의 독립 성능 검증과 개선이 필요합니다. 논문의 97.98%를 이 구현의 정확도로 표시하지 않습니다.
