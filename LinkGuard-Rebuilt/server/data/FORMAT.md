# CSV 형식

UTF-8 CSV의 헤더는 `url,label`입니다. 정상 URL은 0, 피싱 URL은 1입니다.

```csv
url,label
https://www.example.com,0
http://delivery-verify.example/login,1
```

위 행은 예약 도메인을 사용하는 **형식 설명용 가상 예시**입니다. 실제 사이트의 안전성 판정이나 학습 데이터셋이 아닙니다. 실제 학습에는 출처·수집 시점·라벨 근거를 확인한 충분한 독립 도메인 데이터가 필요합니다.

중복 URL은 제거하고 충돌 라벨은 거부합니다. 같은 등록 도메인을 학습과 평가 양쪽에 섞지 않습니다. 시간·캠페인·복제 템플릿 중복은 데이터 구축 단계에서도 확인해야 합니다. 단위 테스트의 합성 URL은 파이프라인 검사 전용이며 운영 모델이나 정확도 주장에 사용하지 않습니다.
