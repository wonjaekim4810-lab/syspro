# LinkGuard 다운로드

ZIP과 APK는 생성한 산출물을 재압축·수정하지 않고 그대로 보관한 파일입니다. GitHub 파일 화면에서 **Download raw**로 내려받을 수 있습니다.

- `LinkGuard-Kotlin-Python-Rebuilt.zip`: Kotlin·Python 전체 프로젝트
- `LinkGuard-Python-Rebuilt.zip`: Python 알고리즘·학습·API
- `LinkGuard-debug-Rebuilt.apk`: Android 디버그 설치 파일
- `SOURCES.md`: 전체 소스 텍스트
- `FILES.md`: ZIP 내부 목록
- `SHA256SUMS.txt`: 무결성 확인값

전체 소스는 기본 `master` 브랜치의 `LinkGuard-Rebuilt/` 폴더에도 있습니다. 바이너리 파일은 기본 브랜치와 분리한 `linkguard-downloads-v0.2.0` 브랜치에 보관합니다.
