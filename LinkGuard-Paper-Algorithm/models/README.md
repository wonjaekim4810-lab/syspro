# 별도로 학습한 모델을 넣는 공간

이 폴더에는 운영용 모델이 포함되어 있지 않습니다.

- `ml_v1.joblib`: 외부에서 학습한 NumPy 40특징 입력 sklearn 모델을 `pack_joblib.py`로 포장한 파일을 둘 수 있습니다.
- `feature_net_v1.onnx`: 40개 특징을 받는 외부 학습 ONNX 모델을 둘 수 있습니다. 선택적 ONNX 런타임이 필요합니다.
- URL 문자/토큰 입력 모델은 `linkguard/adapters.py`의 `CustomURLTextAdapter`에 실제 토크나이저·가중치 로드·추론을 구현해야 합니다. 확장자만 바꾸면 연결되는 것은 아닙니다.

파일 배치 후 `modelctl.py register`로 DB에 등록하고 검증 후 활성화하세요. 이름과 버전은 변경 불가능한 산출물 식별자로 사용하고, 기존 파일을 덮어쓰는 대신 새 버전을 등록하세요.

기본 SHA-256은 지정한 모델 파일만 검증합니다. 사용자 정의 DL에 별도 토크나이저/전처리 자료가 필요하면 그 자료의 버전·해시 검증도 사용자 정의 어댑터에 구현하세요.

실제 모델 파일은 기본 Git/소스 ZIP에 포함하지 않습니다.
